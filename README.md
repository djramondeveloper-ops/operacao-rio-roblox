# OPERAÇÃO RIO — Roblox RP

Jogo multiplayer de roleplay brasileiro ambientado em uma cidade fictícia inspirada no Rio de Janeiro.

## Visão
- 7 comunidades com identidade própria e disputa de território
- PMERJ e BOPE com carreiras, equipamentos e ocorrências
- Inventário persistente, armas e veículos
- Loja VIP com Game Passes e Developer Products
- Sistema de baque PvP entre facções, com regras e cooldowns
- Foco em jogadores reais; sem IA de NPCs

## Stack
Roblox Studio, Luau, Rojo e GitHub.

## Primeiros passos
1. Instale Roblox Studio e Rojo.
2. Abra este repositório no Codex.
3. No terminal, execute `rojo serve` na raiz do projeto.
4. No Roblox Studio, use o plugin Rojo para conectar o projeto.
5. Teste em modo servidor + clientes antes de publicar.

## Desenvolvimento
A fase 1 estabelece a estrutura do projeto e uma base de serviços. Sistemas de produção serão implementados e testados incrementalmente. Não há promessa de jogo pronto nesta fase.

## Segurança
Toda compra, alteração de inventário, combate e disputa territorial deve ser validada no servidor. Nunca confiar em valores enviados pelo cliente.
